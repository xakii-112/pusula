# Short-sale volume data (FINRA Reg SHO, point in time)

Generated by `tools/shortvol_report.py` from the store built by `pusula data short-volume`. Data quality only: no return is read here.

* source `https://cdn.finra.org/equity/regsho/daily/CNMSshvolYYYYMMDD.txt`, sessions 2018-08-01 to 2026-10-23, 19,892,234 rows, 23,910 symbols, sessions without a file: none
* per-file SHA-256 chain `92d9e6bc7eaa5095`
* a session's file is used from the next session's close (FINRA publishes it after the close, observed 17:16 ET)

## Identity: is it the member's own volume?

FINRA names a stock by the ticker it had that day; a security id carries today's ticker. For every member year the correlation of daily log-volume changes between the FINRA volume read for the security and its own bars is measured (clipped changes, so a split in the adjusted bar volume does not break it). Same company: typically 0.6-0.9. A year below 0.35 was investigated; the earlier tickers found that way are in `src/pusula/data/ticker_history.py`.

* member years measured: 4632; quantiles of the correlation: {0.01: 0.479, 0.05: 0.552, 0.25: 0.653, 0.5: 0.724}
* member years with no FINRA rows under the security's tickers: 0
* member years with rows on too few days to measure (under 40): 1
* member years below 0.35: 1
